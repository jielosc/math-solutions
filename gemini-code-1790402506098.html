概率分布列与数学期望综合题

考查模型：置换群的对称性、0-1指示变量法

📝 原题内容

17.（15分） 将编号为 $1, 2, \cdots, n\ (n \geqslant 3, n \in \mathbf{N}^*)$ 的 $n$ 个小球随机放入编号为 $a_1, a_2, \cdots, a_n$ 的盒子，每个盒子里仅放一个小球，设编号为 $a_i\ (1 \leqslant i \leqslant n, i \in \mathbf{N}^*)$ 的盒子里小球的编号为 $b_i$，若 $b_i = i$，则称该小球为“配球”。

(1) 当 $n = 3$ 时，求“配球”个数 $X$ 的分布列和期望；

(2) 已知：若随机变量 $X_i$ 服从两点分布，且 $P(X_i = 1) = p_i,\ P(X_i = 0) = 1 - p_i,\ i = 1, 2, \cdots, n$，则 $$E\left(\sum_{i=1}^n X_i\right) = \sum_{i=1}^n p_i$$

  • (ⅰ) 求“配球”个数 $X$ 的期望；
  • (ⅱ) 若 $b_i$ 满足：当 $i = 1$ 时，$b_i > b_{i+1}$；当 $i = n$ 时，$b_i > b_{i-1}$；当 $2 \leqslant i \leqslant n-1$ 时，$b_i > b_{i-1}$ 且 $b_i > b_{i+1}$，则称该小球为“顶球”，求“顶球”个数 $Y$ 的期望。
💡 详细解析与思路
核心方法：0-1指示变量法与期望的线性性
当求解计数型随机变量的期望时，若直接求联合分布极其繁琐，可以通过引入指示变量拆分为单点概率之和，即 $E(\sum X_i) = \sum P(X_i=1)$。无论变量之间是否独立，该公式均成立。
(1) 求 $n=3$ 时 $X$ 的分布列与期望

当 $n=3$ 时，全排列总数 $3! = 6$ 种：

  • $(1, 2, 3)$：配球数为 3；
  • $(1, 3, 2),\ (3, 2, 1),\ (2, 1, 3)$：配球数均为 1；
  • $(2, 3, 1),\ (3, 1, 2)$：配球数均为 0。

因此随机变量 $X$ 取值为 $0, 1, 2, 3$（不存在恰好 2 个配球的情况）：

  • $P(X = 0) = \dfrac{2}{6} = \dfrac{1}{3}$
  • $P(X = 1) = \dfrac{3}{6} = \dfrac{1}{2}$
  • $P(X = 2) = 0$
  • $P(X = 3) = \dfrac{1}{6}$
$X$ 0 1 2 3
$P$ $\dfrac{1}{3}$ $\dfrac{1}{2}$ $0$ $\dfrac{1}{6}$

期望计算为： $$E(X) = 0 \times \frac{1}{3} + 1 \times \frac{1}{2} + 2 \times 0 + 3 \times \frac{1}{6} = 1$$

(2)(ⅰ) 求“配球”个数 $X$ 的期望

设指示变量 $X_i$：第 $i$ 个球为配球时 $X_i=1$，否则为 $0$。由对称性：

$$P(X_i = 1) = \frac{(n-1)!}{n!} = \frac{1}{n}$$

利用期望的线性性累加：

$$E(X) = \sum_{i=1}^n P(X_i = 1) = n \times \frac{1}{n} = 1$$
(2)(ⅱ) 求“顶球”个数 $Y$ 的期望

设指示变量 $Y_i$ 代表位置 $i$ 是否为“顶球”：

  1. 两端端点 ($i=1$ 与 $i=n$)：
    仅需比单侧相邻大，由大小对等性： $$P(Y_1=1) = P(b_1 > b_2) = \frac{1}{2}, \quad P(Y_n=1) = P(b_n > b_{n-1}) = \frac{1}{2}$$
  2. 中间位置 ($2 \leqslant i \leqslant n-1$)：
    需在 $\{b_{i-1}, b_i, b_{i+1}\}$ 三数中最大。由轮换对称性，三个互异数字中任一个最大的概率均为 $\frac{1}{3}$： $$P(Y_i=1) = \frac{1}{3}$$

求和可得：

$$\begin{aligned} E(Y) &= P(Y_1=1) + P(Y_n=1) + \sum_{i=2}^{n-1} P(Y_i=1) \\ &= \frac{1}{2} + \frac{1}{2} + (n-2) \times \frac{1}{3} = \frac{n+1}{3} \end{aligned}$$

环形传递博弈与期望的线性性

从“全班硬币游戏”到“小朋友分糖果”：透过表象看本质

双题同台对照

题型 A（54人硬币）

54人围成一圈，每人1枚硬币。同时独立等概率选择：保留、给左边、给右边。求手中空手人数期望 $E(X)$。

最终期望： $16$
题型 B（12人糖果）

12名小朋友围成一圈，每人1颗糖。同时独立等概率将糖果给左侧或给右侧（不保留）。求手中空手人数期望 $E(Y)$。

最终期望： $3$

参量解构与机制对比

比较维度 题型 A（54人硬币） 题型 B（12人糖果）
总人数 $n$ $n = 54$ $n = 12$
个人行动选项 3 种（左、留、右，各 $\frac{1}{3}$） 2 种（左、右，各 $\frac{1}{2}$，不保留）
潜在给入来源 3 处（自己、左邻、右邻） 2 处（自身必出，仅看左邻、右邻）
单人“空手”概率 $$P = \left(1 - \frac{1}{3}\right)^3 = \frac{8}{27}$$ $$P = 1 \times \left(\frac{1}{2}\right) \times \left(\frac{1}{2}\right) = \frac{1}{4}$$
总期望计算 $$E(X) = 54 \times \frac{8}{27} = 16$$ $$E(Y) = 12 \times \frac{1}{4} = 3$$

三层本质透析：为什么能一眼秒杀？

第一层：破解“分布列陷阱”——期望的普适线性性

环上相邻人员是否空手强相关，如果执着于求分布列 $P(X=k)$ 会陷入图论与容斥死循环。利用期望线性性质公式： $$E\left(\sum_{i=1}^n I_i\right) = \sum_{i=1}^n E(I_i)$$ 该式完全不要求变量间相互独立，极大简化了计算。

第二层：视角维度的跃迁——从“发射追踪”到“受体漏斗”
顺向追踪“物品送给了谁”会导致状态呈树状爆炸。 逆向思维：只盯准某一个口袋作为“受体”，直接计算所有能向其注水的独立源头“恰好都未投递给它”的概率。

第三层：微观独立的保真性

虽然全局相邻口袋相关，但在微观切片下，决定某个特定口袋的所有源头（如左邻居和右邻居）是独立自主行动的，直接适用乘法公式。

此类环形分配问题的通用秒杀母公式
若环上有 $n$ 人，保留概率 $p_S$，左传概率 $p_L$，右传概率 $p_R$（满足 $p_S + p_L + p_R = 1$），则空手人数期望恒为： $$E = n \cdot (1 - p_S) \cdot (1 - p_R) \cdot (1 - p_L)$$
